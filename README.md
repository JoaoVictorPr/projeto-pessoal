# projeto pessoal
📌 Sobre o projeto

Este projeto é um site pessoal em desenvolvimento contínuo, criado com o objetivo de aplicar na prática os conhecimentos adquiridos durante meus estudos em Análise e Desenvolvimento de Sistemas, com foco em desenvolvimento backend e fundamentos web.

O site evolui conforme novos conteúdos são estudados, testados e consolidados. Por esse motivo, estrutura, layout e funcionalidades podem sofrer alterações frequentes.

🎯 Objetivos

Consolidar conhecimentos teóricos por meio da prática

Desenvolver familiaridade com a construção de projetos reais

Aplicar boas práticas de versionamento com Git e GitHub

Criar uma base sólida para projetos futuros mais complexos

🧠 Aprendizados aplicados

Ao longo do desenvolvimento, estão sendo trabalhados e aprimorados conceitos como:

Estruturação semântica de páginas HTML

Estilização e organização visual com CSS

Lógica de programação aplicada ao frontend

Organização de arquivos e pastas

Versionamento de código com Git

Evolução incremental do projeto

🚧 Status do projeto

🔄 Em desenvolvimento

Este repositório representa um ambiente de aprendizado ativo. Algumas partes podem estar incompletas, em refatoração ou em fase de testes, o que é intencional e faz parte do processo de aprendizado.

🚀 Próximos passos (planejamento)

Melhorar a responsividade do layout

Implementar novas funcionalidades gradualmente

Aprimorar a organização do código

Integrar conceitos de backend futuramente
